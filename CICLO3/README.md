
# Ciclo 3 - SlotMachine

## Descripción

Este directorio contiene los productos desarrollados durante el tercer ciclo del proyecto inicial de la asignatura **Desarrollo Orientado por Objetos (DOPO-POOB)**.

El proyecto consiste en desarrollar un simulador inspirado en el problema *Slot Machine* de la maratón de programación internacional 2025. En este ciclo se amplía el sistema para resolver el problema de la maratón y, cuando sea posible, simular la solución obtenida.

## Objetivo del ciclo

El objetivo principal del tercer ciclo fue extender el proyecto **SlotMachine** para incorporar la creación de máquinas con igual número de ruedas y símbolos, la solución del problema de la maratón y la simulación de las acciones necesarias para obtener una configuración ganadora.

Para ello, se trabajó en el diseño del sistema, la implementación de las nuevas funcionalidades y las pruebas necesarias para verificar su comportamiento.

## Resultado del ciclo

Como resultado de este ciclo se desarrollaron los productos de diseño, implementación, pruebas y documentación correspondientes a la nueva extensión del proyecto.

El trabajo se enfocó en:

- Crear una máquina con igual número de ruedas y símbolos.
- Resolver el problema de la maratón mediante la clase `SlotMachineContest`.
- Simular las acciones necesarias para obtener una configuración ganadora, cuando sea posible.
- Verificar el comportamiento del sistema mediante pruebas unitarias y pruebas de aceptación.

De acuerdo con los requisitos de diseño, la máquina debe permanecer invisible durante la resolución del problema y hacerse visible durante la simulación.
