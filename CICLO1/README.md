# Ciclo 1 - SlotMachine

## Descripción

Este directorio contiene los productos desarrollados durante el primer ciclo del proyecto inicial de la asignatura **Desarrollo Orientado por Objetos (DOPO-POOB)**.

El proyecto consiste en desarrollar un simulador inspirado en el problema **Slot Machine** de la maratón de programación internacional 2025. Para este ciclo no se buscaba resolver el problema de la maratón, sino construir el simulador de una máquina tragamonedas.

## Objetivo del ciclo

El objetivo principal del primer ciclo fue construir una primera versión funcional y extensible del simulador **SlotMachine**.

Para lograrlo, se planteó el desarrollo de las funcionalidades necesarias para crear y administrar la máquina tragamonedas, sus ruedas y símbolos, además de permitir su funcionamiento visual.

También se debía realizar el diseño del sistema mediante diagramas en Astah y desarrollar el código siguiendo los requisitos establecidos para el proyecto.

## Resultado del ciclo

Como resultado de este ciclo se obtuvo una primera versión del simulador **SlotMachine**, capaz de realizar las operaciones principales definidas para la entrega.

El proyecto permite:

* Crear una máquina tragamonedas.
* Adicionar y eliminar ruedas.
* Adicionar y eliminar símbolos.
* Girar las ruedas.
* Consultar los símbolos y la configuración actual.
* Verificar si la configuración obtenida es ganadora.
* Controlar la visibilidad del simulador.
* Finalizar el simulador.

Además, se desarrollaron los productos de diseño y documentación correspondientes al ciclo.
