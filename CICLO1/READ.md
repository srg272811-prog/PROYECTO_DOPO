# Proyecto Inicial - Desarrollo Orientado por Objetos

Este repositorio contiene el desarrollo del proyecto inicial de la asignatura **Desarrollo Orientado por Objetos (DOPO-POOB)**.

El proyecto consiste en el desarrollo de un simulador de máquina tragamonedas, organizado por ciclos de desarrollo.

## Estructura del repositorio

```text
/
├── README.md
│
└── Ciclo-1/
    ├── README.md
    ├── Código fuente
    ├── Diagramas de Astah
    └── Retrospectiva.pdf
```

## Ciclos

### Ciclo 1

Contiene la primera entrega del proyecto **SlotMachine**, incluyendo:

* Código fuente.
* Diagrama de clases.
* Diagramas de secuencia.
* Documento PDF con la retrospectiva del ciclo.

## Herramientas utilizadas

* Java
