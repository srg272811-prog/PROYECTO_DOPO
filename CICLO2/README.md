
# Ciclo 2 - SlotMachine

## Descripción

Este directorio contiene los productos desarrollados durante el segundo ciclo del proyecto inicial de la asignatura **Desarrollo Orientado por Objetos (DOPO-POOB)**.

El proyecto consiste en desarrollar un simulador de una máquina tragamonedas inspirado en el problema *Slot Machine* de la maratón de programación internacional 2025. En este ciclo se trabajó en la extensión y mejora del simulador, incorporando nuevas funcionalidades y manteniendo el requisito de extensibilidad.

## Objetivo del ciclo

El objetivo principal del segundo ciclo fue extender la funcionalidad del simulador **SlotMachine** mediante nuevas operaciones para administrar y controlar las ruedas de la máquina.

Las funcionalidades propuestas para este ciclo fueron:

- Intercambiar dos ruedas.
- Fijar y soltar una rueda.
- Rotar una rueda un número determinado de pasos.
- Establecer la máquina en una configuración específica.

También se trabajó en la actualización del diseño del sistema, la implementación de los cambios en Java y la documentación del proyecto.

## Resultado del ciclo

Como resultado de este ciclo se obtuvieron los productos de implementación, diseño y documentación correspondientes a la extensión del simulador **SlotMachine**.

El desarrollo se orientó a incorporar las funcionalidades solicitadas en la guía, conservar la estructura del proyecto y facilitar futuras modificaciones.
